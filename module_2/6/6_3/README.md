# Калькулятор с динамическими библиотеками

## Описание

Калькулятор на языке C с поддержкой динамической загрузки арифметических операций из библиотек `.so`.

Поддерживаемые операции: `+`, `-`, `*`, `/`.

## Структура проекта

```text
calculator/
├── main.c
├── calculator.c / calculator.h
├── parser.c / parser.h
├── operators.c / operators.h
├── view.c / view.h
├── Makefile
└── plugins/
    ├── add.c
    ├── subtract.c
    ├── multiply.c
    └── divide.c
```

## Динамические библиотеки

Каждая операция находится в отдельной библиотеке и экспортирует функцию:

```c
double operation(double a, double b);
```

Библиотеки создаются из файлов:

| Библиотека | Операция |
|---|---|
| `add.so` | `+` |
| `subtract.so` | `-` |
| `multiply.so` | `*` |
| `divide.so` | `/` |

## Загрузка библиотек

Функция `operators_load_directory()` в `operators.c`:

1. Открывает директорию `plugins` с помощью `opendir()`.
2. Находит файлы `.so` через `readdir()`.
3. Загружает библиотеки с помощью `dlopen()`.
4. Получает адрес функции `operation` через `dlsym()`.
5. Сохраняет указатели на функции и библиотеки в массиве операторов.

`apply_operator()` находит нужную операцию и вызывает её через указатель на функцию.

`operators_unload_all()` закрывает библиотеки с помощью `dlclose()` при завершении программы.

## Используемые функции

| Функция | Назначение |
|---|---|
| `dlopen()` | Загрузка библиотеки |
| `dlsym()` | Получение адреса функции |
| `dlerror()` | Проверка ошибок |
| `dlclose()` | Выгрузка библиотеки |
| `opendir()` | Открытие директории |
| `readdir()` | Чтение файлов директории |

## Сборка и запуск

```bash
make
./calculator
```

Очистка проекта:

```bash
make clean
```

Для библиотек используются флаги `-fPIC` и `-shared`. Для основной программы — `-ldl`.

## Проверка

Если удалить одну из библиотек из `plugins`, соответствующая операция не загрузится и будет недоступна в калькуляторе.

**Результат:** арифметические операции вынесены в отдельные динамические библиотеки, которые автоматически загружаются при запуске программы.
