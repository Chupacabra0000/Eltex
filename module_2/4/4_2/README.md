# Приоритетная очередь сообщений 

## Описание программы

Программа реализует приоритетную очередь сообщений на языке C с использованием односвязного списка.

Каждое сообщение содержит:
- `id` — уникальный идентификатор сообщения;
- `priority` — приоритет от 0 до 255 (255 — наивысший приоритет);
- `text` — текст сообщения.

Очередь автоматически сортирует сообщения по убыванию приоритета. Если несколько сообщений имеют одинаковый приоритет, они извлекаются в порядке добавления (FIFO).

## Реализованные операции

1. **Добавление сообщения** — вставка сообщения в очередь с учётом приоритета.
2. **Извлечение первого сообщения** — удаление сообщения с наивысшим приоритетом.
3. **Извлечение по точному приоритету** — удаление первого сообщения с указанным приоритетом.
4. **Извлечение по минимальному приоритету** — удаление первого сообщения, приоритет которого не ниже заданного (`priority >= заданного`).
5. **Просмотр очереди** — вывод всех сообщений в порядке приоритета.

При добавлении проверяется диапазон приоритета и отсутствие повторяющегося ID среди сообщений, находящихся в очереди.

## Структура проекта

- `main.c` — запуск программы, генерация тестовых сообщений и управление меню.
- `model.h`, `model.c` — структуры данных и логика работы приоритетной очереди.
- `view.h`, `view.c` — пользовательский интерфейс, ввод и вывод данных.
- `Makefile` — автоматизация компиляции программы.

В программе используется разделение **Model–View**: логика обработки очереди отделена от пользовательского интерфейса.

## Компиляция и запуск

Для компиляции выполните:

```bash
make
```

Для запуска:

```bash
./priority_queue
```

Для удаления скомпилированных файлов:

```bash
make clean
```

## Тестирование

При запуске программа автоматически добавляет несколько тестовых сообщений с разными приоритетами. После этого пользователь может проверить работу всех операций через меню программы.
